    ## Как пользоваться
    ### Ручное управление Checkbox
    Для контроля над компонентом нужно использовать пропс <CodeOrSourceMdx>checked</CodeOrSourceMdx> и
    обрабатывать клик через <CodeOrSourceMdx>onClick</CodeOrSourceMdx>.

    
    <Source code={`
        import React, {useState} from "react";
        import {Checkbox,FormControlLabel} from "@pcapcc360/chameleon-ui";

        ...

        const [isChecked, setIsChecked] = useState(false);
        const onChange = (e: React.ChangeEvent<HTMLInputElement>, checked: boolean) => {
            setIsChecked(!isChecked)
        };

        ...


        return (
            <FormControlLabel
                control={<Checkbox checked={isChecked} onChange={onChange} />}
                color="default"
                label="Checkbox"
            />
        );
    };
    `} dark/>

    ### Автоматическое управление Checkbox
    Без явного указания checked, всю работу с пропсами и eventListener'ами мы оставляем на
    механизмы внутри библиотеки, что позволяет писать код быстрее.

    <Source code={`
        import React, {useState} from "react";
        import {Checkbox,FormControlLabel} from "@pcapcc360/chameleon-ui";

        ...
        const onChange = (e: React.ChangeEvent<HTMLInputElement>, checked: boolean) => {
            console.log('click')
        };

        ...

        return (
            <FormControlLabel
                control={<Checkbox onChange={onChange} />}
                color="default"
                label="Checkbox"
            />
        );
    };
    `} dark/>

    ## Кастомизация

    Рядом с<CodeOrSourceMdx>Checkbox</CodeOrSourceMdx>можно разместить любой другой компонент.

    Например добавить иконку с хинтом в конце.

    <Paper elevation={1} style={{padding: '15px 10px'}}>
        <Example1 />
    </Paper>

    Исходный код:

        <Source code={`
        import React from "react";
        import {Checkbox,FormControlLabel,Box,Tooltip,Typography} from "@pcapcc360/chameleon-ui";

        ...
        const onChange = (e: React.ChangeEvent<HTMLInputElement>, checked: boolean) => {
            console.log('click');
        };

        ...

        return (
            <Box display="flex" alignItems="center">
                <Checkbox onChange={onChange}/> 
                <Typography>Checkbox с иконкой</Typography>  
                <Tooltip
                    title="Подсказка"
                    placement="top"
                    BoxProps={{padding: "0 8px"}}
                    PopperProps={{
                        popperOptions: {
                            modifiers: [{
                                name: 'offset',
                                options: {
                                    offset: [0,-4]
                                }
                            }]
                        }
                    }}
                >
                    <SvgCircleQuestion />
                </Tooltip>
            </Box>
        );
    };
    `} dark/>

    ### Стилизация


    Чтобы стилизовать checked,unchecked и indeterminate состояния, достаточно передать в <CodeOrSourceMdx>Checkbox</CodeOrSourceMdx>
    три пропса: <CodeOrSourceMdx>icon</CodeOrSourceMdx>, <CodeOrSourceMdx>checkedIcon</CodeOrSourceMdx>, и  <CodeOrSourceMdx>indeterminateIcon</CodeOrSourceMdx>.
    Оба пропса являются ReactNode и рекомендуется стилизовать <CodeOrSourceMdx>span</CodeOrSourceMdx> элемент для них
    как в примере ниже (написано на styled-components, но допустимо любое свое решение):

    <Source code={`
    import { styled, Box } from '@mui/material';
    import { Checkbox } from '@pcapcc360/chameleon-ui';
    import { useStyles } from './styles';

    ...

        borderRadius: 4,
        width: 16,
        height: 16,
        border: \`1px solid green\`,
        backgroundColor: white,
        '.Mui-focusVisible &': {
            outline: \`1px auto blue\`,
            outlineOffset: 1,
        },
        'input:hover:enabled ~ &': {
            borderColor: green,
        },
        'input:active:enabled ~ &': {
            borderColor: green,
        },
        'input:disabled ~ &': {
            borderColor: green,
        },
    }));

    // Иконка, когда Checkbox выбран
    const CheckedIcon = styled(CheckboxIcon)(() => ({
        backgroundColor: green,
        '&:before': {
            display: 'block',
            width: 14,
            height: 14,
            backgroundRepeat: 'no-repeat',
            backgroundPosition: 'center',
            backgroundImage: \`url("data:image/svg+xml,%3Csvg width='10' height='8' viewBox='0 0 10 8' fill='none' xmlns='http://www.w3.org/2000/svg'%3E%3Cpath d='M9.3418 2.1543L4.2793 7.2168C4.15625 7.32227 4.01563 7.375 3.875 7.375C3.73438 7.375 3.59375 7.32227 3.4707 7.2168L0.658203 4.4043C0.447266 4.17578 0.447266 3.82422 0.658203 3.5957L1.2207 3.0332C1.34375 2.92772 1.48438 2.875 1.625 2.875C1.76563 2.875 1.90625 2.92772 2.0293 3.0332L3.875 4.89647L7.9707 0.7832C8.09375 0.677725 8.23438 0.625 8.375 0.625C8.51563 0.625 8.65625 0.677725 8.7793 0.7832L9.3418 1.3457C9.55273 1.57423 9.55273 1.92578 9.3418 2.1543Z' fill='white'/%3E%3C/svg%3E%0A")\`,
            content: '""',
        },
        'input:disabled ~ &': {
            backgroundColor: gray,
            borderColor: black,

            backgroundColor: green,

        },
    }));

    ...

    const CustomCheckbox = () => {
        return (<Box display="flex" alignItems="center">
            <Checkbox checkedIcon={<CheckedIcon />}  indeterminateIcon={<IndeterminateIcon />} icon={<CheckboxIcon />}/>Кастомный чекбокс

    }
        `} dark />
